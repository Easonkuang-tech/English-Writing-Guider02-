# IELTS 正式写作评分系统

版本：v0.1  
适用：IELTS Academic / General Training Writing Task 1 和 Task 2  
用途：正式作文评分、AI 评分提示词、app 评分引擎、历史记录

---

## 1. 目的与边界

本文件只负责正式作文评分，不负责每日句子练习。

正式评分必须基于 IELTS 官方公开的 Writing band descriptors。下面的评分锚点是内部实现摘要，用于帮助 AI 和 app 做结构化判断，不替代官方完整 descriptors，也不代表官方评分结果。

必须遵守：

```text
1. 输出 Estimated Band Range，不声称是官方成绩。
2. 每个 criterion 必须先引用用户原文，再给 band。
3. Task 1 使用 Task Achievement。
4. Task 2 使用 Task Response。
5. Coherence and Cohesion、Lexical Resource、Grammatical Range and Accuracy 两项任务均使用。
6. 四项权重相同。
7. 不使用“使用了很多今日单词”作为直接加分理由。
8. 每轮只给一个 Priority Fix。
```

## 4. 单篇任务评分计算

先给四项各自的 estimated band：

```text
task_band
coherence_band
lexical_band
grammar_band
```

计算：

```text
raw = (
  task_band
  + coherence_band
  + lexical_band
  + grammar_band
) / 4

estimated_band = round_to_nearest_half_band(raw)
```

输出：

```text
Estimated Band: 6.0
Confidence: Medium
```

如果系统同时计算 Task 1 和 Task 2：

```text
writing_band = round_to_nearest_half_band(
  (task1_band + 2 × task2_band) / 3
)
```

## 5. 评分锚点

以下为 app 内部简化锚点，用于指导 AI 判断。生产环境应同时保存官方完整 descriptors。

### 5.1 Task Achievement / Task Response

| Band | 内部判断 |
|---|---|
| 9 | 完整回应任务；内容充分、精准、自然；所有要求均得到处理 |
| 8 | 充分回应任务；主要部分发展完整；观点和证据针对性强 |
| 7 | 清晰回应任务；主要要求均覆盖；观点有发展；Task 2 立场清楚；Task 1 overview 清楚 |
| 6 | 基本回应任务；部分内容发展不足；Task 1 有 overview；Task 2 立场可辨认 |
| 5 | 部分回应任务；观点有限；支持不足或不相关；可能漏掉一部分要求 |
| 4 | 回应很少或偏题；观点不清楚；发展严重不足 |
| 3 | 几乎未回应任务；内容极有限或大量不相关 |
| 2 | 没有有效回应任务 |
| 1 | 只有零散词语，无法形成任务回应 |
| 0 | 没有作答，或内容与任务无关到无法评分 |

Task 1 必须额外检查：

```text
是否有明确 overview
是否选择并比较主要特征
是否用数据支持 description
是否遗漏主要趋势、差异或异常值
是否加入了不必要的解释或原因
```

Task 2 必须额外检查：

```text
是否回答题目的全部问题
是否有清楚且一致的立场
每个主体段是否有 claim + explanation + evidence or example
是否对反方观点做了必要处理
结论是否与全文立场一致
```

### 5.2 Coherence and Cohesion

| Band | 内部判断 |
|---|---|
| 9 | 逻辑推进自然，衔接几乎不被察觉，指代完全清楚 |
| 8 | 段落和信息推进流畅，衔接自然，偶有小瑕疵 |
| 7 | 段落推进清楚，连接手段自然，指代大体明确 |
| 6 | 整体有组织，段落清楚，连接手段有错误但仍可理解 |
| 5 | 有一些组织，但段落和连接关系不稳定 |
| 4 | 组织非常有限，连接词误用，读者需要反复推测 |
| 3 | 组织严重不足，信息关系难以跟踪 |
| 2 | 几乎没有可辨组织 |
| 1 | 只有零散信息，无法判断衔接 |
| 0 | 无有效文本 |

检查：

```text
topic sentence 是否明确
每段是否只处理一个核心任务
连接词是否表达真实逻辑
this / they / ones 等指代是否明确
是否为了连接而堆砌 firstly / moreover / furthermore
```

### 5.3 Lexical Resource

| Band | 内部判断 |
|---|---|
| 9 | 词汇范围广且精准，搭配自然，错误极少 |
| 8 | 词汇范围广，搭配自然，偶有 slip |
| 7 | 有一定词汇灵活性，能使用较不常见词和搭配，偶有错误 |
| 6 | 词汇量足够完成任务，尝试较不常见词汇，错误不妨碍理解 |
| 5 | 词汇基本够用，搭配和词形错误明显 |
| 4 | 词汇范围有限，错误频繁并影响理解 |
| 3 | 词汇严重不足，难以表达基本意思 |
| 2 | 只有少量孤立词汇 |
| 1 | 没有有效词汇控制 |
| 0 | 无有效文本 |

检查：

```text
主题词是否准确
搭配是否自然
是否重复同一个基础词
是否为了“高级”而强行使用不自然表达
拼写、词性、可数性是否正确
```

### 5.4 Grammatical Range and Accuracy

| Band | 内部判断 |
|---|---|
| 9 | 句型范围广，几乎全篇准确，错误极少 |
| 8 | 句型范围广，多数句子准确，错误不影响表达 |
| 7 | 句型有变化，常见错误较少，有较多无误句 |
| 6 | 简单句和复杂句混合，有错误但通常不阻碍理解 |
| 5 | 句型范围有限，复杂句尝试少，错误频繁 |
| 4 | 句型非常有限，基础错误频繁，影响理解 |
| 3 | 语法结构严重不足，难以形成完整句子 |
| 2 | 基本无法形成可理解的语法结构 |
| 1 | 只有零散结构 |
| 0 | 无有效文本 |

检查：

```text
主谓一致
句子边界
动词形式
冠词和复数
从句使用
比较结构
条件句
是否有完整主干
```

## 6. AI 正式评分流程

AI 必须按以下顺序执行：

1. 识别 Task 1 或 Task 2。
2. 检查字数和是否完整作答。
3. 给四项 criterion 分别评分。
4. 每项先引用用户原文，再给 band。
5. 计算 Estimated Band Range。
6. 只选一个 Priority Fix。
7. 给一个最小修改示范。
8. 保存 rubric 版本、模型版本和用户原文。

## 8. AI 系统提示词

```text
You are an IELTS writing evaluator.

Use the official IELTS Writing band descriptors as the source of truth.
For Task 1, use Task Achievement.
For Task 2, use Task Response.
Use Coherence and Cohesion, Lexical Resource, and Grammatical Range
and Accuracy for both tasks.

Rules:
1. Never present your result as an official score.
2. Every score must cite specific evidence from the user's text.
3. Evaluate the four criteria independently.
4. Give only one priority fix per response.
5. Do not reward target vocabulary if it is inaccurate or unnatural.
6. Preserve the user's meaning and voice.
7. Show a minimal rewrite, not a complete ghostwritten replacement.
8. Do not invent evidence, task requirements, or word counts.
9. Return structured output in the required schema.
10. Preserve rubric version and model version metadata.
```
