# 日常写作练习评分系统

版本：v0.1  
适用：简易写作、快速输出、句子练习、词伙和句式复用  
用途：每日练习评分、目标表达追踪、app 练习模式

---

## 1. 目的与边界

这个系统负责“今天有没有把新学内容真正用出来”，不负责预测 IELTS 正式分数。

它不输出：

```text
Estimated IELTS Band
Task Response band
Coherence band
Lexical Resource band
Grammatical Range band
```

原因：

```text
短文本、单段和 3-5 句练习没有足够证据判断完整 IELTS band。
```

它输出：

```text
Daily Practice Score
Target Vocabulary Usage
Target Pattern Usage
One Priority Fix
Revision Prompt
Tomorrow Reuse Context
```

---

## 2. 两种练习

### 2.1 Quick Output

适用：

```text
3-5 个句子
一个观点加一个理由
一个词伙复用任务
一个句式复用任务
快速纠错
```

### 2.2 Mini Paragraph

适用：

```text
50-100 词
一个清楚观点
一个原因或例子
2-3 个目标表达
```

两种模式都使用同一个 Daily Practice Rubric。

---

## 3. Daily Practice Rubric

满分：10

| 项目 | 分数 | 判断问题 |
|---|---:|---|
| Task Relevance | 0-2 | 是否回答当前题目或写作目标 |
| Idea Clarity | 0-2 | 是否有清楚的核心观点和关系 |
| Target Vocabulary | 0-2 | 今日词伙是否被正确、自然使用 |
| Target Pattern | 0-2 | 今日句式是否被正确使用 |
| Sentence Control | 0-2 | 主干、动词形式、句子边界和搭配是否基本正确 |

### 3.1 评分细则

```text
2 = 完成且自然
1 = 部分完成，但需要修正
0 = 未完成、无法理解或明显误用
```

### 3.2 各部分检查

Task Relevance：

```text
是否直接回应练习目标
有没有偏题
有没有只堆词而不表达观点
```

Idea Clarity：

```text
有没有一个清楚的中心
观点和理由是否连接
代词和目标对象是否明确
```

Target Vocabulary：

```text
目标词伙是否出现
搭配是否正确
词性是否正确
语境是否自然
```

Target Pattern：

```text
目标句式是否出现
结构是否完整
动词形式是否正确
是否被强行塞入不自然的句子
```

Sentence Control：

```text
主语和谓语是否完整
主谓一致
句子边界
动词形式
冠词和复数
常见拼写
```

## 5. Usage Tracker

Usage Tracker 检查今日词伙和句式是否真正被使用、用对、用得自然。它不直接增加或减少 IELTS band。

### 5.1 表达记录

```text
expression
meaning
source_sentence
detected
detected_count
correct_count
incorrect_count
natural
context_appropriate
status
next_review
```

状态：

```text
New
Controlled
Reused
Spontaneous
```

### 5.2 句式记录

```text
pattern
user_original
correct_structure
detected
correct
incorrect
natural
new_context
status
next_review
```

### 5.3 使用指标

```text
Usage Rate = detected target items / assigned target items
Accuracy Rate = correct target items / detected target items
Naturalness = natural uses / detected target items
```

展示格式：

```text
Target vocabulary: 4 / 5 used
Target patterns: 2 / 3 used
Correct usage: 5 / 6 detected
Unnatural usage: 1
```

禁止：

```text
Because you used 5 target words, your Lexical Resource is +1 band.
```

原因：强制使用新词不等于 IELTS 得分提高，错误搭配甚至可能降低分数。


### 6.2 今日句式

```text
pattern:
example:
meaning:
constraints:
common_error:
planned_reuse_context:
```

示例：

```text
pattern: cause + someone + to + verb
example: Environmental problems may cause companies to change
their production methods.
constraints: cause 后接宾语，再接 to + 动词原形
common_error: cause companies change / cause companies to changing
```

## 7. Prompt Matching

题库题目必须带 metadata，避免只靠关键词把词伙硬塞进不相关主题。

```text
prompt_id
task_type
topic
writing_function
required_functions
common_collocations
target_vocabulary_compatibility
target_pattern_compatibility
difficulty
time_limit
```

匹配逻辑：

```text
1. 主题匹配
2. 写作功能匹配
3. 词伙语境是否自然
4. 句式是否适合该题型
5. 用户当前难度
6. 最近重复度
```

例如：

```text
circular economy
适合：environment, sustainability, production, business responsibility
不适合：health, education, culture
```

## 8. AI 练习反馈流程

1. 检查是否回应练习目标。
2. 检测今日词伙和句式。
3. 分别判断正确、错误、自然和不自然。
4. 按 Daily Practice Rubric 给 10 分。
5. 只给一个 Priority Fix。
6. 给最小改写提示，不代写完整答案。
7. 保存 Usage Tracker。

## 10. AI 系统提示词

```text
You are a daily English writing coach.

This is short practice, not a full IELTS essay.
Do not assign an IELTS band.

Use the Daily Practice Rubric:
Task Relevance, Idea Clarity, Target Vocabulary,
Target Pattern, and Sentence Control.

Rules:
1. Check the user's target vocabulary and patterns separately.
2. Do not reward forced or unnatural target usage.
3. Give a score out of 10.
4. Give only one priority fix.
5. Show a minimal rewrite prompt, not a complete ghostwritten answer.
6. Preserve the user's original idea.
7. Save usage status and next review date.
8. Return structured output in the required schema.
```

## 13. 最终原则

```text
Daily Practice Rubric 负责完成度和复用质量。
Usage Tracker 负责词汇和句式是否真正进入写作。
正式 IELTS 分数由《雅思正式写作评分系统.md》负责。
两个系统必须分开显示，不能混成一个分数。
```
